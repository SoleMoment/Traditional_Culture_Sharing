## 项目分析：`lab-civics-net`（机房素养网）

### 项目概述

这是一个面向中小学信息技术课程教学的**局域网应用**，用于在机房环境中模拟互联网服务，帮助学生理解网络通信、邮件系统、即时通讯和网络安全等概念。

### 技术栈

| 组件 | 技术 |
|------|------|
| 后端框架 | Node.js + Express |
| 数据库 | SQLite (better-sqlite3) |
| 实时通信 | Socket.io |
| 文件上传 | Multer |
| 会话管理 | express-session |
| 密码加密 | bcryptjs |

### 核心功能模块

#### 1. **用户系统**
- 学生注册/登录（用户名支持中文、字母、数字、下划线）
- 教师账号（默认：`teacher` / `teacher123`，可通过环境变量修改）
- 角色区分：student / teacher

#### 2. **模拟邮箱系统** (`/api/mail/*`)
- 注册即获得邮箱地址：`用户名@jifang.lab`
- 支持收件、发件、抄送功能
- 邮件详情查看与已读标记

#### 3. **即时聊天室** (Socket.io)
- 多房间支持（默认「大厅」）
- 历史消息保留最近 80 条
- 实时消息广播

#### 4. **作品空间** (`/api/posts/*`)
- 发帖功能（标题、正文）
- 附件上传（支持 png/jpg/gif/webp/pdf/txt，默认 8MB 限制）
- 点赞、评论功能

#### 5. **文明规范与举报**
- 举报功能（针对帖子、评论、聊天消息）
- 教师后台可查看举报记录并删除不当内容

### 数据库结构

| 表名 | 用途 |
|------|------|
| `users` | 用户信息 |
| `email_messages` | 邮件内容 |
| `email_recipients` | 邮件收件人/抄送关系 |
| `chat_messages` | 聊天记录 |
| `posts` | 作品帖子 |
| `post_comments` | 作品评论 |
| `post_likes` | 作品点赞 |
| `reports` | 举报记录 |

### 项目特点

1. **离线可用**：所有依赖（包括 Socket.io 客户端）都已打包到本地，无需外网
2. **部署简单**：单文件 SQLite 数据库，复制 `data/` 目录即可备份
3. **教学适配**：功能设计对应教材单元（邮件、聊天、网络文明公约）
4. **安全考虑**：密码加密存储、会话管理、文件类型限制

```bash
npm install
npm start
```

默认监听 `0.0.0.0:3000`，学生机通过教师机局域网 IP 访问。

## 问题原因

## 修复内容

修改了 `server/index.js` 中的 `getUserByUsername` 函数：

```javascript
function getUserByUsername(name) {
  // 处理邮箱格式，如 lisi@jifang.lab 提取用户名 lisi
  let username = String(name || '').trim();
  if (username.includes('@')) {
    username = username.split('@')[0];
  }
  return db.prepare('SELECT id, username, display_name, role FROM users WHERE username = ? COLLATE NOCASE').get(username);
}
```

现在支持两种格式：
- `lisi`（纯用户名）
- `lisi@jifang.lab`（完整邮箱地址）

服务器会自动提取 `@` 符号前的用户名进行查找。
